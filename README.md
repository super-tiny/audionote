# AudioNote

Offline player for long local lessons. Import keeps a reference to the original file. Resume position, listened ranges, and timed notes stay on the device. Android and iOS bundles are built in GitHub Actions.

Architecture: [docs/ARCHITECTURE.md](docs/ARCHITECTURE.md).

## Requirements

- Node.js 22 (see `.nvmrc`)
- Android bundles: JDK 17, Android SDK 37, build-tools 37.0.0, NDK 27.1.12297006
- iOS bundles: macOS with Xcode 26.4 or newer

Playback uses `@rntp/player` (React Native Track Player v5). Personal and educational use is free. Commercial use needs a license from the package authors.

## Develop

```bash
npm ci
npm start
```

A development build is required. Expo Go cannot load the native player.

```bash
npm run android
npm run ios
```

## Bundles

Android, from this repo on Linux or macOS:

```bash
npm run build:android
```

Outputs:

- `android/app/build/outputs/apk/release/*.apk`
- `android/app/build/outputs/bundle/release/*.aab`

iOS, on macOS:

```bash
bash scripts/build-ios.sh
```

Output: `dist/ios/*.ipa`.

Without signing secrets the Android release APK is signed with the debug keystore (sideload it), and the IPA is unsigned. Play upload and App Store signing are described in the architecture doc.

## GitHub

| Workflow | Result |
| --- | --- |
| CI | Unit tests, typecheck, and a JavaScript bundle export |
| Mobile bundles | APK, AAB, and IPA artifacts. Tag `v*` also publishes a GitHub Release |
| EAS bundle | Manual. Needs the `EXPO_TOKEN` secret and a linked Expo project |

`android/` and `ios/` are generated by `expo prebuild` and are not committed.
